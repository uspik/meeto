# Meeto

Telegram-бот и mini-app для организации мероприятий: календарь, приглашения,
лимит мест с листом ожидания и кворум с автоотменой.

## Структура репозитория

| Путь | Что это |
|---|---|
| [`app/`](app/) | Рабочее приложение: бэкенд, бот, воркер, mini-app, docker-compose |
| [`app/DEPLOY.md`](app/DEPLOY.md) | Развёртывание с нуля: сервер, домен, сертификат, BotFather |
| [`app/README.md`](app/README.md) | Устройство приложения и решения по архитектуре |
| [`SPEC.md`](SPEC.md) | Спецификация продукта: роли, права, логика кворума, API, экраны |
| [`schema.sql`](schema.sql) | Референсная схема БД для PostgreSQL |
| [`calendar-prototype.html`](calendar-prototype.html) | Интерактивный прототип UI — эталон вёрстки |

Прототип открывается двойным щелчком в браузере и работает без сервера:
внутри моковые данные. Это исходный образец, по которому собран mini-app.

## Быстрый старт

```bash
cd app
cp .env.example .env      # заполнить токен, домен, секреты
./scripts/init-cert.sh    # первый сертификат Let's Encrypt
docker compose up -d --build
```

Подробно, включая покупку сервера и настройку BotFather, — в
[`app/DEPLOY.md`](app/DEPLOY.md).

## Тесты

```bash
cd app/backend && python -m tests.smoke
```

Сквозной сценарий на SQLite: подпись initData, роли и права, овербукинг,
лист ожидания, кворум, пересечения, приватность ссылки на созвон, аутбокс.
